What it includes

What the repository demonstrates

A modular demo architecture covering issuer, verifier, holder wallet, and client SDK. The repository is a technical reference; it does not claim certification, regulatory compliance, or production readiness.

Key capabilities

  • A sample credential issuance flow using OID4VCI and holder proof.
  • A sample presentation flow using OID4VP and verifier-side authorization.
  • TypeScript SDK with PKCE, callback handling, and token lifecycle management.
  • An Ionic/Angular sample wallet for QR-based issuance and presentation journeys.
  • Shared Java foundation to reduce duplication and simplify maintenance.

FAQ

Questions about the demo

What is an SSI platform?

An SSI (Self-Sovereign Identity) platform enables verifiable digital credentials, with user-controlled data and service-side cryptographic verification.

Which flows does the demo show?

OID4VCI handles issuance of digital credentials to the wallet. OID4VP handles credential presentation and verification during login, onboarding, or authorization.

Is this certified or production-ready?

It is presented as a demo and integration reference. The repository does not establish protocol conformance, EUDI Wallet or eIDAS compliance, security assurance, or production readiness. These require separate evidence and deployment-specific assessment.

Why use it in an enterprise context?

Potential benefits depend on the credential, wallet, verifier, and operating model selected. This demo does not establish fraud reduction or regulatory compliance for a deployed service.
