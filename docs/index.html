Why SSI Ecosystem

Everything you need to build
identity-first applications

From credential issuance to wallet-based verification — all standards-compliant, all wired together, and all open source.

🪪

OID4VCI Credential Issuance

Issue verifiable credentials to wallet holders using the OpenID for Verifiable Credential Issuance spec. Pre-authorized code grants, proof-of-possession JWTs, and SPID operator login out of the box.

✅

OID4VP Credential Verification

Verify wallet presentations using OpenID for Verifiable Presentations. The verifier acts as an OAuth 2.0 authorization server, issuing tokens that represent the verified holder context for your application.

🛠️

Reusable TypeScript SDK

Integrate SSI verification into any Angular app in minutes with @izylife/ssi-auth-client. PKCE, token lifecycle, redirect recovery, and an HttpClient interceptor — all handled.

Modules

Six modules, one mono-repo

Each module owns a clearly defined slice of the SSI stack and can be understood independently.

ssi-issuer :9090

Operator issuer portal. Exposes OID4VCI metadata, credential offer endpoints, token exchange, and credential signing. Manages the full onboarding state machine and pushes real-time updates to the Angular UI over WebSockets. Supports SPID SAML for operator authentication.

Spring Boot 3.2 Angular 17 MongoDB OID4VCI SPID/SAML
ssi-verifier :9091

Operator verifier portal. Generates OID4VP request objects, accepts wallet presentation responses, validates VP tokens, and issues short-lived authorization codes. Doubles as an OAuth 2.0 authorization server for verifier-facing client apps.

Spring Boot 3.2 Angular 17 MongoDB OID4VP OAuth 2.0
ssi-client-application :9092

Sample verifier-side integration. Shows how a third-party web app delegates SSI verification to the verifier portal, exchanges the authorization code for an access token, and decodes the credential_preview claims for display.

Spring Boot 3.5 Angular 20 ssi-client-lib PKCE
ssi-client-lib npm package

Reusable TypeScript SDK. Provides a framework-agnostic core client and an Angular integration layer. Handles PKCE, state management, redirect callbacks, token refresh scheduling, storage, and an optional HttpClient bearer token interceptor.

TypeScript Angular 20 tsup PKCE
ssi-wallet :8100 (dev)

Holder-side mobile wallet. Scans QR codes, parses credential offers and presentation requests, redeems OID4VCI tokens, builds and submits VP tokens, stores credentials securely, manages did:key identities, and supports biometric auth.

Ionic 8 Angular 20 Capacitor 7 Android
ssi-common library

Shared Java library consumed by both issuer and verifier backends. Centralizes common DTOs, domain types, and utilities to avoid duplication across services. Built as part of the root Maven reactor and installed into the local repository before other modules.

Java 17 Maven
Runtime Flows

How it works end-to-end

Two main runtime paths — credential issuance for onboarding, and credential presentation for login.

1
Operator requests credential offer

The issuer portal generates a QR code containing a credential offer URI.

Issuer Portalssi-issuer
2
Wallet scans and resolves the offer

The holder's wallet scans the QR, fetches the issuer metadata and resolves the credential offer.

ssi-walletssi-issuer
3
Token exchange with pre-authorized code

Wallet POSTs to /oidc4vci/token and receives an access token and c_nonce.

ssi-walletssi-issuer
4
Wallet builds a proof JWT and requests the credential

Proof is signed with the wallet's EC key material. The issuer signs and returns the verifiable credential.

ssi-walletssi-issuer
5
Credential stored and onboarding completed

The wallet stores the credential and notifies the issuer. The UI receives a WebSocket update marking onboarding complete.

ssi-walletssi-issuerIssuer Portal
1
Client app starts the verifier flow

The Angular app calls beginVerifierFlow() on the SDK, which generates PKCE params and redirects the browser to the verifier portal.

ssi-client-applicationssi-client-lib
2
Verifier portal shows a QR code

The verifier generates a request object and renders a QR for the wallet to scan.

ssi-verifierVerifier Portal
3
Wallet submits a Verifiable Presentation

Wallet fetches the request object, selects matching credentials, builds a VP token, and POSTs to /oidc4vp/responses.

ssi-walletssi-verifier
4
Verifier validates and issues an authorization code

VP token, nonce, state, and descriptor map are verified. A short-lived authorization code is issued and the browser is redirected back.

ssi-verifier
5
SDK exchanges the code for tokens

The SDK completes the PKCE exchange at /oauth2/token, persists the access/refresh tokens, and emits them to the Angular app.

ssi-client-libssi-verifierssi-client-application
Quick Start

Up and running in minutes

Prerequisites: Java 17+, Maven 3.9+, Node.js 18+, MongoDB 7+ or Docker.

Start all services 
# 1. Start MongoDB
docker run --name ssi-mongo \
  -p 27017:27017 -d mongo:7

# 2. Build shared library
mvn -pl ssi-common install -DskipTests

# 3. Start services via Makefile
make run-ssi-demo

# Issuer  → http://localhost:9090
# Verifier → http://localhost:9091
# Client  → http://localhost:9092
Install the TypeScript SDK 
# Install from npm
npm install @izylife/ssi-auth-client

# Angular app.config.ts
export const appConfig: ApplicationConfig = {
  providers: [
    provideSsiAuth({
      baseUrl: 'http://localhost:9091',
      redirectUri: window.location.origin,
      clientId:    window.location.origin,
      portalPath:  '/verifier',
    })
  ]
};
Docker Compose (issuer + verifier + keycloak) 
# Copy env template and configure
cp .env.example .env

# Start full stack
docker compose up --build

# Keycloak admin UI
# → http://localhost:8180/admin
# Issuer   → http://localhost:9090
# Verifier → http://localhost:9091
Run the wallet (web / Android) 
# Web dev mode
cd ssi-wallet
make serve
# → http://localhost:8100

# Android (first time)
make add-android
make build
make sync
make run-android
