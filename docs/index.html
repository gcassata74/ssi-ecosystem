Piattaforma pronta per emissione, verifica e integrazione applicativa

Un'architettura modulare che copre issuer, verifier, wallet e SDK client, con stack moderno e flussi gia testati in ambienti di sviluppo reali.

Capacita chiave

  • Emissione credenziali con OID4VCI e prova crittografica del holder.
  • Verifica presentazioni con OID4VP e tokenizzazione del contesto utente.
  • SDK TypeScript con PKCE, callback handling e gestione lifecycle token.
  • Wallet mobile per QR scan, storage sicuro e gestione identita did:key.
  • Base Java condivisa per ridurre duplicazioni e semplificare manutenzione.
